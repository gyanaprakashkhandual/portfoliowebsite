# Gyana Prakash Khandual — Portfolio Website

A modern, fast, and responsive single-page portfolio website built to showcase my journey as a Software Engineer & Full Stack Developer.

## Features

- Clean and minimal design
- Dark/Light mode toggle (with persistence)
- Smooth scroll animations and reveal effects
- Interactive project filtering by category
- Fully responsive (mobile-first)
- SEO-friendly and fast loading
- Built with pure HTML, CSS & JavaScript (No frameworks)

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Syne + DM Sans)
